# グラスロジック — Glass Logic

Meta Ray-Ban Display 用のお絵かきロジック（ノノグラム）パズル。行と列の数字ヒントを頼りにD-padでマスを塗っていくと、正解の瞬間、視界の中にドット絵が浮かび上がります。答えの絵柄はクリアするまで「？？？」のおたのしみ。

- **ライブURL**: https://glass-nonogram.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / 静的サイト）

## 特徴

- **D-pad と相性抜群のパズル** — ↑↓←→でカーソル移動、タップで「ぬる → ✕しるし → けす」の3状態切り替え。ノノグラムの操作がグラスの入力だけで完結
- **そろった行・列はヒントが薄くなる** — いまどのラインが確定済みかがひと目でわかる
- **正解でドット絵がカラーで出現** — クリアすると絵柄と名前（＋絵文字）をお披露目。ホーム一覧の「？？？」も解放される
- **全6問収録** — 5×5（かんたん〜ふつう）4問＋10×10（むずかしい）2問。10×10は5マスごとの区切り線つき
- **ベストタイム記録** — パズルごとのクリアタイムを localStorage に保存し、ベスト更新も表示
- **オフライン動作** — API 不使用。すべてタップ＋D-padスライドだけで往復可能

## 操作方法

| 画面 | 操作 |
|------|------|
| ホーム | ↑↓でパズルを選んでタップ |
| プレイ画面 | ↑↓←→でカーソル移動（左右は端でループ）、タップでマスを ぬる→✕→けす。盤面の一番下からさらに↓で「× やめてもどる」へ |
| クリア画面 | 「つぎのパズルへ →」または「ホームへ」 |
| PC確認用 | Escape でもどる（グラスの戻るジェスチャーは使用不可のため補助のみ） |

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E3%83%AD%E3%82%B8%E3%83%83%E3%82%AF&appUrl=https%3A%2F%2Fglass-nonogram.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラスロジック`、URL `https://glass-nonogram.vercel.app` を入力。
